# Curso JavaScript Moderno 🟨

Mis apuntes y ejercicios del curso **JavaScript Moderno: Guía para dominar el lenguaje**, de Fernando Herrera (Udemy).

Voy subiendo el código a medida que avanzo en el curso. Cada carpeta corresponde a una sección.

## Avance

| Sección | Tema | Estado |
|---------|------|--------|
| [01-Fundamentos](01-Fundamentos) | Primeros pasos: `alert`, `prompt`, `confirm`, variables con `let` y `const`, y uso de la consola (`console.log`, `console.table`) | 🚧 En curso |

## ¿Cómo ver los ejercicios?

Cada sección tiene un `index.html`. Ábrelo en el navegador y revisa la consola con **F12** (o **Cmd + Option + I** en Mac) para ver los resultados.
