## ¿Cómo ver los ejercicios?

Cada sección tiene un `index.html` que carga un script a la vez. Para cambiar de ejercicio, deja sin comentar la línea `<script>` del archivo que quieras ver y comenta las demás.

Abre el `index.html` en el navegador y revisa la consola con **F12** (o **Cmd + Option + I** en Mac) para ver los resultados.
